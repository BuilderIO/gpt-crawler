## Understanding ChatGPT Limits

ChatGPT has specific limits for file uploads:

| Limit Type                   | Value     | Description                              |
| ---------------------------- | --------- | ---------------------------------------- |
| **Max Tokens per File**      | 2,000,000 | Text files cannot exceed 2M tokens       |
| **Max File Size**            | 512 MB    | Hard limit for any single file           |
| **Max Files per GPT**        | 20        | You can upload up to 20 files to one GPT |
| **Max User Storage**         | 10 GB     | Total storage limit per user             |
| **Max Organization Storage** | 100 GB    | Total storage limit per organization     |

> **Note**: Spreadsheet files don't have the 2M token limit, but still have the 512MB file size limit.

## Automatic File Splitting

GPT Crawler automatically splits your output files when they exceed ChatGPT limits:

### Basic Configuration

```typescript
// config.ts
export const defaultConfig: Config = {
  url: "https://example.com",
  match: "https://example.com/**",
  maxPagesToCrawl: 1000,
  outputFileName: "output.json",

  // These options control automatic splitting:
  maxTokens: 1800000, // 1.8M tokens (safe buffer)
  maxFileSize: 450, // 450MB (safe buffer)
};
```

### What Happens During Automatic Splitting

1. **Crawling**: GPT Crawler collects all your data
2. **Analysis**: The output file is analyzed for token count and file size
3. **Splitting**: If limits are exceeded, the file is automatically split
4. **Output**: You get multiple files like `output-1.json`, `output-2.json`, etc.

### Example Output

```

Wrote 1000 items to output.json

📊 File Analysis:
   Items: 1,000
   Estimated tokens: 2,300,000
   File size: 45.2 MB
   ⚠️  File exceeds ChatGPT limits - splitting automatically...

✅ Successfully split into 2 files:
   1. output-1.json: 550 items, 1,265,000 tokens, 24.8 MB
   2. output-2.json: 450 items, 1,035,000 tokens, 20.4 MB

💡 Upload tip: You can upload up to 20 files to a single ChatGPT.
```

## Manual File Splitting

You can also manually split existing JSON files using our CLI utility:

### Basic Usage

```bash
# Split a single file
npx tsx src/split-json.ts output.json

# Analyze without splitting
npx tsx src/split-json.ts output.json --analyze-only

# Split with custom limits
npx tsx src/split-json.ts output.json --max-tokens 1500000 --max-size 400
```

### Advanced Options

```bash
# Split multiple files
npx tsx src/split-json.ts *.json

# Custom output directory and prefix
npx tsx src/split-json.ts output.json --output-dir ./split-files --output-prefix my-data

# Preserve array structure
npx tsx src/split-json.ts output.json --preserve-array

# Verbose output
npx tsx src/split-json.ts output.json --verbose
```

### CLI Options Reference

| Option                     | Description                          | Default        |
| -------------------------- | ------------------------------------ | -------------- |
| `--analyze-only`           | Only analyze files without splitting | false          |
| `--max-tokens <number>`    | Maximum tokens per file              | 1,800,000      |
| `--max-size <number>`      | Maximum MB per file                  | 450            |
| `--max-files <number>`     | Maximum number of output files       | 20             |
| `--output-dir <directory>` | Output directory for split files     | Same as input  |
| `--output-prefix <prefix>` | Prefix for output files              | Input filename |
| `--preserve-array`         | Keep array structure in output files | false          |
| `--min-items <number>`     | Minimum items per file               | 1              |
| `--verbose`                | Show detailed output                 | false          |

// Conservative (safe for all scenarios)
maxTokens: 1500000,  // 1.5M tokens

maxTokens: 1800000,  // 1.8M tokens

// Aggressive (close to limit)

### File Size Limits

```typescript
// Conservative (safe for all scenarios)
maxFileSize: 400,  // 400MB

// Recommended (good balance)
maxFileSize: 450,  // 450MB

// Aggressive (close to limit)
maxFileSize: 500,  // 500MB
```

### Smart Splitting Options

```typescript
export const config: Config = {
  // ... other options

  // Split based on token count (recommended for text-heavy content)

  // Both limits work together - whichever is hit first triggers splitting
};
```

## Troubleshooting

### Problem: Files Still Too Large After Splitting

**Symptoms**: Individual items are very large, causing single files to exceed limits.

**Solutions**:

1. Reduce `maxPagesToCrawl` to get fewer, smaller pages
2. Use more specific selectors to get less content per page
3. Lower the `maxTokens` or `maxFileSize` settings

```typescript
// Example: More conservative splitting
export const config: Config = {
  maxPagesToCrawl: 100, // Fewer pages
  maxTokens: 1000000, // 1M tokens instead of 1.8M
  maxFileSize: 300, // 300MB instead of 450MB
  selector: ".main-content", // More specific selector
};
```

### Problem: Too Many Files Generated

**Symptoms**: More than 20 files created, exceeding ChatGPT's file limit.

**Solutions**:

1. Increase token or size limits to create fewer, larger files
2. Create multiple ChatGPTs for different file groups
3. Combine related content before splitting

```typescript
// Example: Create fewer files
export const config: Config = {
  maxTokens: 1900000, // Higher token limit
  maxFileSize: 480, // Higher size limit
};
```

### Problem: Split Files Are Too Small

**Symptoms**: Many files with very few items each.

**Solutions**:

1. Increase `minItemsPerFile` in the CLI tool
2. Adjust splitting thresholds

```bash
# Ensure at least 10 items per file
npx tsx src/split-json.ts output.json --min-items 10
```

### Problem: Token Count Estimation Issues

**Symptoms**: Files appear to be under limits but still get rejected by ChatGPT.

**Solutions**:

1. Use more conservative token limits
2. Double-check with manual analysis

```bash
# Analyze your files
npx tsx src/split-json.ts *.json --analyze-only --verbose
```

## Best Practices

### 1. Use Conservative Limits

Always leave a buffer below the actual ChatGPT limits:

```typescript
// ✅ Good: Conservative with buffer
maxTokens: 1800000,    // 200k buffer below 2M limit
maxFileSize: 450,      // 62MB buffer below 512MB limit

// ❌ Risky: Too close to limits
maxTokens: 1990000,    // Only 10k buffer
maxFileSize: 510,      // Only 2MB buffer
```

### 2. Plan for Multiple GPTs

If you have lots of content, plan to use multiple ChatGPTs:

```typescript
// Strategy: Create themed file groups
export const docsConfig: Config = {
  url: "https://docs.example.com",
  outputFileName: "docs-knowledge.json",
  maxTokens: 1800000,
};

export const blogConfig: Config = {
  url: "https://blog.example.com",
  outputFileName: "blog-knowledge.json",
  maxTokens: 1800000,
};
```

### 3. Monitor Output During Crawling

Watch the console output to understand your file sizes:

```
📊 File Analysis:
   Items: 1,000
   Estimated tokens: 2,300,000
   File size: 45.2 MB
   ⚠️  File exceeds ChatGPT limits - splitting automatically...
```

### 4. Test with Small Batches First

Start with small crawls to understand your content's token density:

```typescript
// Start small to understand your data
export const testConfig: Config = {
  maxPagesToCrawl: 10, // Small test first
  outputFileName: "test-output.json",
};
```

### 5. Use Appropriate Selectors

Choose selectors that balance comprehensiveness with efficiency:

```typescript
// ✅ Good: Focused on main content
selector: ".main-content, .article-body",

// ❌ Too broad: Includes navigation, ads, etc.
selector: "body",

// ❌ Too narrow: Misses important content
selector: "p",
```

## Integration with Existing Workflows

### Programmatic Usage

```typescript
import { splitJSONFile, analyzeJSONFile } from "./src/file-splitter.js";

// Analyze a file
const analysis = await analyzeJSONFile("output.json");
console.log(`File has ${analysis.estimatedTokens} tokens`);

// Split if needed
if (!analysis.withinChatGPTLimits) {
  const result = await splitJSONFile("output.json", {
    maxTokensPerFile: 1800000,
    maxBytesPerFile: 450 * 1024 * 1024,
  });
  console.log(`Split into ${result.outputFiles.length} files`);
}
```

### Custom Build Scripts

```typescript
// scripts/build-knowledge.ts
import { crawl, write } from "./src/core.js";
import { splitJSONFile } from "./src/file-splitter.js";

async function buildKnowledge() {
  // Crawl the site
  await crawl(config);

  // Write and auto-split
  const outputFile = await write(config);

  console.log(`Knowledge base ready: ${outputFile}`);
}
```

## Need Help?

If you're still having issues with file sizes:

1. **Check the console output** - GPT Crawler provides detailed information about file analysis and splitting
2. **Use the analyze command** - Run `--analyze-only` to understand your files without splitting
3. **Start with conservative limits** - Use smaller token and size limits until you find what works
4. **Consider multiple GPTs** - Sometimes it's better to organize content across multiple ChatGPTs by topic

Remember: It's better to have multiple smaller files that work reliably than one large file that gets rejected by ChatGPT!
